## 후보 목록 (권장 순서)

### 1. 용어집(고유명사 사전) 기반 STT 후보정
- **가치**: 상 — Whisper가 한국어 인명·사내용어·제품명을 자주 틀리는 문제를 정면 해결. 전사 품질은 모든 하위 기능(요약·액션아이템·후속조치 대조)의 품질을 결정하므로 파급 효과가 가장 크다.
- **난이도**: 중
- **구현 스케치**
  - 신규 테이블 `glossary` (term, aliases, category) + CRUD API. 기존 `speakers`/`categories` CRUD 패턴 재사용 가능.
  - 전사 후처리: 유사도(편집거리/자모 단위) 기반 치환. 과잉 치환 방지를 위해 임계값 설정 필요 —
    기존 `voice_profiles` 의 threshold 설정 API(`GET/PUT /api/voice-profiles/threshold`) 패턴을 그대로 따를 것.
  - 요약 프롬프트에 용어집 주입 → `claude -p` 가 올바른 표기를 쓰도록.
  - 설정 화면(SettingsModal)에 용어 관리 탭 추가.
- **주의**: 치환은 되돌릴 수 있어야 한다. 원본 transcript를 보존하고 표시 시점에 적용하거나, 치환 이력을 남길 것.

### 2. 액션아이템 마감일 + 지연 표시
- **가치**: 중상 — 액션아이템 대시보드(PR #71)와 후속조치 대조(PR #76)가 이미 있는데 **기한 개념만 없다**. 이 둘을 실제 관리 도구로 만드는 마지막 조각.
- **난이도**: 중
- **구현 스케치**
  - 액션아이템 구조에 `due_date` 추가. 현재 구조는 `{text, assignee, done}` (`PATCH /api/jobs/{id}/action-items`).
  - 요약 시 `claude -p` 가 발화에서 기한을 추출하도록 프롬프트 확장("다음 주 금요일까지" → 절대 날짜).
    **AI 추출은 추정이므로 사용자가 수정 가능해야 한다** — PR #76의 `ai_status`/`user_status` 이원화 패턴을 따를 것.
  - `/action-items` 페이지에 기한 필터·정렬, 지연 항목 배지, 사이드바 지연 건수.
- **주의**: 기존 액션아이템(due_date 없음)에서 모든 화면이 정상 동작해야 한다.

### 3. 하이라이트 클립 추출·공유

  - 공유 토큰 구조(PR #72의 `share_token`)를 클립에도 확장할지, 별도 테이블로 둘지는 director 판단.

### 4. 이메일 / Slack 발송
- **가치**: 중 — 공유 링크가 이미 있으므로 그 위의 얇은 전달 레이어.

- **가치**: 상
- **난이도**: 상 — **리서치 선행 필수**
- **쟁점**

## 착수 전 참고 — 세션 52에서 얻은 교훈

**테스트가 통과해도 기능이 동작하지 않을 수 있다.**
PR #76은 최초 제출 시 185개 테스트를 통과했으나, 핵심 기능에 사용자 진입점이 없었고 사용자 확정이 저장되지 않았다.
원인은 테스트가 전부 DB 직접 조작 또는 엔드포인트 직접 호출이라 **실제 사용자 경로를 지나지 않았기 때문**이다.

→ 위 후보들은 모두 UI가 개입한다. 다음 조건을 TDD 지시에 반드시 포함할 것:
1. 프론트엔드가 **실제로 보내는 payload 형태**로 API를 호출하는 테스트
2. 사용자가 화면에서 밟는 **경로 전체**(예: 시리즈 할당 → 대조 생성)를 재현하는 테스트
3. 새 컬럼·필드가 **NULL인 기존 데이터**에서 모든 화면이 정상 동작하는지 검증

**PR #64 레이아웃 가드**: `MainArea.tsx` 우측 컬럼에 새 컴포넌트를 넣을 때는 반드시
`flex-shrink-0 overflow-y-auto max-h-[35%]` 래퍼 **안에** 둘 것. PR #75에서 이 실수가 재발했었다.

**DEVGUIDE.md**: 확정 결정사항은 섹션 10, 신규 API는 섹션 6에 기록한다(CLAUDE.md 규칙).
PR #71~#75가 이를 누락해 PR #76에서 일괄 반영했으므로, 앞으로는 각 PR에서 바로 갱신할 것.
