## 2. 확정 구현 스펙 (director 확정, 팀리드 승인)

### 모듈 계약 — 신규 `backend/app/transcript.py`
```python
# Segment = {"start": int|None, "label": str|None, "text": str, "raw": str|None}
#   raw 는 정규 렌더가 원본 줄과 바이트 동일하지 않을 때만 채운다 (같으면 키 생략)
def parse(transcript: str) -> list[Segment]
def render(segments, speaker_map: dict | None = None) -> str
def get_segments(job: dict) -> list[Segment]   # lazy 파싱 + 조회 시 백필
```
- 파싱 정규식 `^\[(\d+):(\d{2})\]\s(.+?):\s(.*)$` — **분은 `\d+` 무제한**(finalize `\d{2}` 결함 고정 지점).
  `[HH:MM:SS]` 허용. 라벨은 `.+?` (**`\S+` 금지** — 공백 포함 실명 "김 팀장" 통과 필수).
- 매칭 실패 줄은 버리지 않는다 → `{"start":None,"label":None,"text":<원문>}` 통과 라인.
- `render`: `"\n".join`, **후행 개행 유무까지 보존**.
- **`label is None` 세그먼트는 `speaker_map`이 무엇이든 `text`를 원문 그대로 출력. 치환 일절 없음.**
  본문에 `SPEAKER_00` 문자열이 있어도 손대지 않는다 — 나이브 `.replace` 본문 오염 계열의 봉쇄점.
- `get_segments`: 백필 전 `render(parsed) == job["transcript"]` 검증. **불일치면 DB에 쓰지 않고**
  파싱 결과만 반환 + 경고 로그.

## 3. 생산자 출력 포맷 바이트 대조 (실측)

정규형 렌더 `f"[{mm:02d}:{ss:02d}] {label}: {text}"` 와 두 생산자 출력이 **일치함을 확인**:

| 생산자 | 코드 | 조인 | 후행 개행 |
|--------|------|------|-----------|
| `merge_and_save` | `timestamp = f"[{minutes:02d}:{seconds:02d}]"` (492) → `f"{prev_timestamp} {prev_speaker}: {prev_text}"` (507·511) | `"\n".join(lines)` | **없음** |
| `_parse_txt_transcript` 변환 경로 | `f"[{normalized_ts}] {speaker_id}: {combined_text}"` (1652), `normalized_ts = f"{int(m):02d}:{int(s):02d}"` (1650) | `'\n'.join` | **없음** |

→ 두 생성 경로 모두 **`raw` 0건 왕복**이 성립해야 한다.
100분 초과는 `{minutes:02d}`가 자연히 3자리로 늘고 파서 `\d+`가 받으며, 렌더의 `:02d`도 3자리를 자르지 않아 복원된다.

## 4. 경계 조건 (합격 기준 해석에 직결 — 놓치면 오판한다)

### 4-1. `raw` 0건 단언의 적용 범위
`_parse_txt_transcript`에는 **업로드 원본을 그대로 반환하는 분기 2개**가 있다:
- 표준 형식 감지 시 `return raw, standard_speakers, {}` (1598 부근)
- 형식 불명 시 `return raw, [], {}` (1638 부근)

이 `raw`는 **사용자 업로드 원본**이라 정규형 보장이 없다(공백 2개, 탭, 자릿수 등).
- **`raw` 키 0건 단언은 *생성된* 출력에만 적용된다** — `merge_and_save` 출력, ClovaNote **변환** 출력(1652 경로).
- **업로드 원본 통과 분기에서는 `raw`가 생겨도 정상.** 여기서 요구되는 건 오직 **바이트 동일성**이다.
  억지로 정규화해 `raw`를 없애려 하면 **사용자 파일을 조용히 변조**하는 것이 된다. 금지.

### 4-2. 콜론 뒤 공백이 없는 줄 (미해결 — 지시 대기)
계약 정규식의 `\s(.*)$`는 공백 1개를 요구하므로 `[00:00] SPEAKER_00:` (빈 발언)은 헤더로 인식되지 않고
`label=None` 통과 라인이 된다.
- 생산자 2곳은 빈 텍스트 세그먼트를 건너뛰므로(`audio_processor.py:484 if not text: continue`)
  **생산 경로에서는 발생하지 않는다.** 손편집 transcript에서만 가능.
- 무손실(raw 통과)이라 데이터는 깨지지 않으나, **그 줄은 PR B의 라벨 치환 대상에서 빠진다.**
- 정규식 유지 vs `\s?` 완화는 director 지시 대기. 임의 변경하지 않는다.

### 4-3. 오디오 경로의 쓰기/읽기 왕복
`merge_and_save`가 파일에 쓰고 `job_queue`가 **읽어서** transcript를 만든다. 왕복이 끼므로
`render(segments) == 파일에서 읽어온 문자열` 을 그 지점에서 성립시켜야 한다 (인코딩·후행 개행 포함).
